# Undangan Azzah & Bayu

Undangan pernikahan interaktif 3D (voxel) dalam satu file: `index.html`.

## Cara pakai
- Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings > Pages > Deploy from a branch > main / root).
- Foto pengantin: taruh `foto-azzah.jpg` dan `foto-bayu.jpg` di folder yang sama dengan `index.html`.

## Yang masih contoh (ganti sebelum disebar)
- QRIS dan nomor rekening di fungsi `kado()` / `qrDummy()`.
- Lokasi di tombol "Buka di Maps" (fungsi `show`, bagian `detail`).

## Catatan teknis
- three.js r128 dimuat dari cdnjs.
- Tanpa build step, tanpa dependensi lain.
